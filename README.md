# Supermarket Simulator

A supermarket simulation project built with Python.

## About

This project simulates a simple supermarket shopping experience through the terminal.

The user can:
- View available products and stock
- Choose products to buy
- Select quantities
- Add multiple products to the cart
- Remove products from the cart
- Check if products are in stock
- Complete or cancel a purchase
- Receive a purchase receipt
- Return to the supermarket after a purchase

## Features

- Product inventory system
- Shopping cart
- Stock availability checking
- Quantity validation
- Purchase total calculation
- Cash balance management
- Receipt generation
- Input validation
- Multiple purchases in the same session

## Technologies

- Python
- Dictionaries
- Lists
- Loops
- Functions
- Conditional statements
- Input validation

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python supermarket.py
